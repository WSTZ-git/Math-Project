# 严格化改写指南（Deep Learning 项目，2026-11）

本指南供逐章改写使用。目标不是“润色”，而是让每个数学环境在不读上下文时也能
确定对象、假设与结论。改写时以插件规范 §3.11 为准。

## 一、必须遵守

1. **只改环境体**：`definition`、`theorem`、`proposition`、`lemma`、`corollary`
   的正文，以及为保持行文通顺而必须调整的紧邻一句话。不要改章节标题、公式编号、
   label、图片、习题题干、目录、参考文献。
2. **每个陈述自足**：开头写“设……”，逐项给出：
   - 数域/空间：$\mathbb{R}$、$\mathbb{C}$、概率空间、向量空间、图 $G=(V,E)$ 等；
   - 对象类型与形状：向量维数、矩阵行×列、方阵、实/复、对称、正定、可逆、
     函数定义域/陪域、随机变量分布、张量各轴长度；
   - 指标范围、参数范围、正则性（连续/可微/可测/可积）、概率假设（独立/同分布/
     期望存在）、非退化条件（非空、非零、分母非零、矩阵可逆）；
   - 量词顺序（对任意/存在/唯一）。
3. **结论完整**：写清“对哪些对象、在什么条件下、成立什么”。不能只留一个公式；
   公式前后必须有文字说明。
4. **禁止口语与元叙述**：环境体内不得出现“我们、可以、其实、显然、注意、这就、
   也就是说、换句话说、不过、当然、例如、直观上、不妨、容易看出、来看、想想、
   有趣的是”，也不得出现“重构新增、补写、原书、译文、本工程、笔者”。
   动机、直观、历史、边界讨论放入紧随其后的 `remark`（可新建）。
5. **不写“（重构新增）”**：任何位置都不要写这四个字。
6. **习题**：只保留题面，不写 `solution`、不写解答。
7. **证明**：不要用“显然/类似地/容易验证/易证/读者可证”代替推导；若原证明有
   这些词，补出具体步骤或改为引用已证结果。证明中不要写“原书未给证明/补全如下”
   之类的元叙述，直接给证明。
8. **保持忠实**：不改变原结论、不加强假设来“救”结论、不删除条件。若原陈述按
   字面为假，保留原陈述并在紧随的 `remark` 中用“原文问题说明”指出，再给出
   修正版本（修正版本可作为新的 proposition/theorem，或直接在原环境内改为正确
   陈述并在 remark 说明原文缺口）。

## 二、句式模板

定义：

```latex
\begin{definition}[名称]\label{definition:...}
设 $X$ 是……，$Y$ 是……（写出类型、维数、定义域）。若
\begin{enumerate}
  \item ……；
  \item ……，
\end{enumerate}
则称 $X$ 为……（记作……）。
\end{definition}
```

定理/命题：

```latex
\begin{proposition}[名称]\label{proposition:...}
设……。若……，则……。
\end{proposition}
```

若条件只有一两条，可直接写在“设……”句中；三条以上用 `enumerate`。

## 三、典型改法

**矩阵对象**：不能只写“设 $\bm{A}$ 为矩阵”。要写
“设 $\bm{A}\in\mathbb{R}^{M\times N}$”或“设 $\bm{A}$ 为 $N\times N$ 实对称
正定矩阵”。用到逆时写“设 $\bm{A}$ 可逆”；用到行列式时写“设 $\bm{A}$ 为
$N\times N$ 方阵”；协方差矩阵写“设 $\bm{\Sigma}\in\mathbb{R}^{D\times D}$
对称正定”。

**模型/公式**：不能只写一个公式。要写输入空间、输出空间、参数空间、映射形式、
以及公式成立的条件。例如：
“设输入空间 $\mathcal{X}\subseteq\mathbb{R}^{D}$，输出空间
$\mathcal{Y}\subseteq\mathbb{R}^{K}$，参数 $\bm{w}\in\mathbb{R}^{P}$。
若映射 $f(\cdot;\bm{w}):\mathcal{X}\to\mathcal{Y}$ 具有形式……，则称其为……。”

**概率对象**：写清样本空间、分布、独立性、期望/方差存在性。例如：
“设 $(\Omega,\mathcal{F},\mathbb{P})$ 为概率空间，$X:\Omega\to\mathbb{R}$
为随机变量，且 $\mathbb{E}[X^{2}]<\infty$。”

**定义中的“称为”**：定义必须能判定。避免“能够”“丰富”“大规模”“语义”等
没有操作含义的词；若必须保留，写明“这里‘大规模’指……”。

## 四、改写后自检

对每个改过的文件运行：

```bash
python3 audit-revision/check_file.py contents/Chapter-XX/section-YY.tex
```

要求：RIG-002/009/010/011 零 ERROR；RIG-003/004/005/006/007/008 逐条处理
（可保留合理 WARN，但要在文件末尾的 `audit-revision/rigor-notes.md` 记一句
理由）。不要用改检查器、删检查项、改 label 的方式“通过”。

## 五、不要做的事

- 不要重写整节散文，不要把正文改成摘要。
- 不要新增没有原书依据的定理。
- 不要改 `\label`、`\cref`、公式编号；若必须拆分环境，先确认引用仍可解析。
- 不要动 `main.tex`、`image/`、`figure/`、`audit-revision/`（本指南与脚本除外）。
- 不要写“重构新增”“补写”“原书”等字样。
